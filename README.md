I.
MODALITÉ DE RENDU
A. NOMDUFICHIER
Créez un fichier texte qui doit avoir un nom au format suivant.
{PROMOTION}_ALGO_{NOM}_{PRENOM}_PARTIE_1.txt
Exemple avec un stagiaire fictif, appelé ici, Nerona Imu, de la promotion CDA2048 :
CDA2048_ALGO_NERONA_IMU_PARTIE_1.txt
Vous pouvez utiliser d’autres extensions
.doc .docx .odt .pdf .rtf
B. OÙL’ENVOYER
Utilisez Moodle, la section dédié pour envoyer votre devoir dans les temps.
C.
